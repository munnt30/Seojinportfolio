# 🎨 My Art Portfolio

미국 미대(애니메이션 · UX/UI) 지원용 개인 포트폴리오 웹사이트입니다.
Claude Code와 함께 한 단계씩 만들어 가는 학습 프로젝트예요.

## 폴더 구조

```
portfolio/
├── index.html                 ← 메인 페이지 (소개, 작품 목록, 연락처)
├── projects/
│   ├── animation-sample.html  ← 애니메이션 작품 상세 페이지 템플릿
│   ├── uxui-sample.html       ← UX/UI 케이스 스터디 템플릿
│   └── drawing.html           ← 드로잉 갤러리 (클릭하면 크게 보기)
├── css/style.css              ← 디자인 (색, 글꼴, 레이아웃)
├── js/main.js                 ← 동작 (필터, 다크모드, 스크롤 효과)
└── images/                    ← 작품 이미지를 여기에 넣으세요
```

## 보는 방법

- 가장 쉬운 방법: `index.html`을 더블클릭
- 또는 터미널에서 `python3 -m http.server 8000` 실행 후 http://localhost:8000 접속

## 🧑‍🎓 Claude Code에게 이렇게 말해 보세요 (학습 단계별)

**1단계 — 내 정보로 바꾸기**
- "Your Name을 내 이름 ○○○으로 모두 바꿔줘"
- "About Me를 이 내용으로 다시 써줘: (한국어로 자유롭게) — 영어로, 고등학생 말투로 자연스럽게"
- "메인 색을 감귤 오렌지 대신 제주 바다색으로 바꿔줘"

**2단계 — 작품 넣기**
- "images 폴더에 넣은 tangerine.jpg를 첫 번째 카드 썸네일로 넣어줘"
- "내 Vimeo 영상 링크(…)를 애니메이션 페이지에 임베드해줘"
- "sketchbook 작품 페이지를 새로 만들어줘. 이미지 12장을 갤러리처럼 보여주고 클릭하면 크게 보이게"

**3단계 — 디자인 다듬기**
- "첫 화면에 내 캐릭터가 걸어가는 작은 애니메이션을 CSS로 넣어줘"
- "휴대폰에서 봤을 때 이상한 곳이 있는지 확인하고 고쳐줘"
- "이 코드가 어떻게 작동하는지 한 줄씩 설명해줘" ← 배우는 데 가장 좋은 질문!

**4단계 — 세상에 공개하기**
- "이 사이트를 GitHub Pages로 무료 배포하는 방법을 단계별로 알려줘"

## 💡 미대 포트폴리오 팁

- **과정(process)을 보여주세요.** RISD, CalArts, SVA, ArtCenter, Parsons, SCAD 같은 학교는
  완성작만큼 스케치·스토리보드·실패한 시도·배운 점을 중요하게 봅니다.
- **관찰 드로잉(observational drawing)** 을 꼭 포함하세요. 많은 애니메이션 학과가 요구합니다.
- 작품 수는 보통 **12~20점**입니다 (학교별 요구사항 확인). 적더라도 좋은 작품 위주로.
- 공식 제출은 대부분 **SlideRoom** 으로 하지만, 개인 웹사이트 링크는 자기소개서와 이력서에 넣으면 좋아요.
- 글은 **본인의 목소리**로 쓰세요. AI는 구조와 문법을 돕는 용도로만 쓰고, 생각과 이야기는 직접.
